A colour picker Kodi doesn't ship

Kodi's own colour wheel only exists from version 20 (Nexus) on. ScenePass carries its own — a 48-swatch grid, plus hex and R/G/B fields for an exact match — built to work back to Kodi 19, fully reachable by d-pad.

Hover a swatch — this is the exact grid, eight hues across six bands from grayscale down to pastel.

Getting started

Reads what ScenePass already found

Point it at a library ScenePass has scanned and it takes over from there — no separate configuration of where episodes live.

01

Add the repository

Install repository.lynxstrike from a zip source, then install service.scenepass from it like any other add-on.

02

No sidecar, no button

ScenePass looks for a .sp.json file next to each video — the output of a ScenePass library scan — and simply does nothing without one.

03

Press play

Colours default to amber for intro, blue for recap — open Settings → Appearance any time to make them yours.
